# Mountain Piper — mountainpiper.com

The website for Mountain Piper, a bagpipe performance and lessons business
(Kit Rashid & Alex Stewart) based in Asheville, North Carolina.

**Traditional Scottish bagpiping and interceltic music** — weddings, funerals
and memorials, festivals, corporate events, ceremonies, and bagpipe lessons,
serving Asheville and Western North Carolina.

## Architecture

A **static, SEO-first multi-page site** built with [Vite](https://vite.dev).
Every page is real, hand-written HTML — no client-side rendering — so all
content, titles, meta descriptions, and structured data are crawlable without
JavaScript. JavaScript is used only for progressive enhancement (mobile menu,
reveal-on-scroll, form validation).

| Route                  | File                              | Purpose                                  |
| ---------------------- | --------------------------------- | ---------------------------------------- |
| `/`                    | `index.html`                      | Services overview, service area, FAQ     |
| `/weddings/`           | `weddings/index.html`             | Wedding bagpiper service page            |
| `/funerals-memorials/` | `funerals-memorials/index.html`   | Funeral / memorial bagpiper service page |
| `/events/`             | `events/index.html`               | Festivals, corporate, ceremonies         |
| `/bagpipe-lessons/`    | `bagpipe-lessons/index.html`      | Lessons with Kit Rashid & Alex Stewart   |
| `/about/`              | `about/index.html`                | About the pipers & the music             |
| `/contact/`            | `contact/index.html`              | Inquiry form + direct contact            |
| `/404.html`            | `404.html`                        | Friendly 404 (noindex)                   |

## SEO implementation

- Exactly one `h1` per page; logical `h2`/`h3` hierarchy; semantic landmarks
  (`header`, `nav`, `main`, `article`, `section`, `footer`, `address`).
- Unique title tags and meta descriptions on every page; canonical URLs;
  Open Graph + Twitter cards; `robots.txt` and `sitemap.xml`.
- JSON-LD structured data: `LocalBusiness` + `MusicGroup` (home), `WebSite`,
  `Service` (each service page), `FAQPage` (visible FAQs only), `Person`
  (about), `BreadcrumbList` (all interior pages), `ContactPage`.
- NAP (name / phone / email / locality) consistent across header, footer,
  contact page, and schema.
- No fabricated reviews, testimonials, pricing, availability, awards, or
  credentials — biographical claims come only from the business's own copy.

## Performance

- Responsive AVIF/WebP/JPEG image variants generated by
  `scripts/optimize-images.mjs`; `width`/`height` reserved to prevent CLS;
  hero image preloaded + `fetchpriority="high"`; everything else lazy-loaded.
- Two self-hosted variable fonts (Fraunces, Inter, latin subsets) with
  `font-display: swap` and preload hints. No third-party scripts at all.

## Accessibility

Skip link, keyboard-operable menu with focus trap and `Escape` to close,
`aria-current` page indication, visible focus styles, reduced-motion support,
labeled form fields with screen-reader-announced inline errors.

## Commands

```bash
npm install
npm run dev       # local dev server
npm run build     # production build to dist/
npm run preview   # preview the production build
```

Original photography lives in `assets-src/images/`; optimized web variants in
`public/images/`. To regenerate optimized images (requires `npm i --no-save sharp`):

```bash
node scripts/optimize-images.mjs
```
